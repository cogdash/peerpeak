Achievement sharing webapp used as a DevOps practice ground.
Blazingly fast!!

---
### Running the app
Install prerequisites:
```shell
python3 -m venv .venv
source .venv/bin/activate
pip install .
```
Run it:
```shell
uv run fastapi dev
```
